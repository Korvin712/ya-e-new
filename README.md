# Я є. I Am. — оновлена збірка v2

Це цілісний сайт із єдиною темно-синьою/золотистою палітрою. Старі навігаційні блоки приховані; інтерактивна логіка інструментів залишена. Перемикач УКР / ENG у верхньому правому куті сайту змінює мову на всіх сторінках, включно з новими головною, каталогом і тестом.

Важливо: відкривайте через локальний вебсервер (`python -m http.server 8000`) або GitHub Pages, а не через `file://` — статті використовують JSON.

# Я є. I Am. — нова збірка (2026-11-13)

Двомовний адаптивний статичний сайт для GitHub Pages.

## Перевірка

1. Розпакуйте ZIP.
2. У папці з `index.html` виконайте `python -m http.server 8000`.
3. Відкрийте `http://localhost:8000/`. Це потрібно для завантаження JSON-статей.
4. Перевірте всі інструменти, обидві мови, мобільну навігацію і експорт результатів.

## Публікація

Після тестування можна завантажити вміст папки в репозиторій GitHub Pages. Поточний сайт не змінено. Перед заміною живого сайту обов’язково зробіть резервну копію репозиторію.

## Структура

- `index.html` — нова головна сторінка; `tools.html` — каталог інструментів.
- `archetype-test.html` — тест V0.8 з новими українськими запитаннями та англійським перекладом.
- Решта HTML модулів — робочі версії оригінального сайту з новою спільною шапкою. Їхня внутрішня логіка не переписувалася.
- `posts.json` — 85 двомовних статей; `anekdoty.json` — гумор; `archetypes.json` — наявні архетипні матеріали.
- `assets/site.css`, `assets/site.js` — спільна мобільна навігація і перемикач мов.
- `images` — оригінальні зображення.

## Обмеження

- На старих сторінках залишаються частини початкового оформлення; спільна шапка забезпечує нову навігацію, але дизайн всіх компонентів ще не абсолютно уніфікований.
- У старих інструментах перемикання мови успадковано з оригінальних модулів.
- Архетипний тест не надсилає дані на сервер і не має кабінету користувача.
- Авторизації й оплат немає.
- Переклад тесту створено для цієї збірки; рекомендується редакторська перевірка носієм англійської.
- Оригінальні статті/архетипи збережено без редакторських змін.
